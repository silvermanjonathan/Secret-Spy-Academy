Classified · Recruits Only

How the Academy week works

Each day opens with a Morning Briefing, runs two build blocks with a break in the Safe House, and closes with a Mission Debrief (show your work, running) and a Field Notebook entry (exit ticket). Your capstone, a Commissioned Edition of Target Lock (a playable chase-and-score game you redesign), must be finished by the end of Day 4. Day 5 is the Final Debrief: presentations and the badge ceremony, nothing else.

HOUSE LAW: ONE CHANGE PER RUN · READ IT, TRACE IT, THEN RUN IT

Print the Field Notebook, one per agent. Every day writes in it.

Pages open in order. Every briefing is now issued, all nine side missions included; the seven newest form the Cryptography Wing.

Week map & pacing model (teacher panel)

The shape of the week

Novelty is front-loaded on purpose and decays to zero; integration rises to replace it, so total load stays roughly flat. The drill (chunk) is the pacing unit, so days are unequal by design. The rhythm is heavy, heavy, heaviest, build, present.

Laws enforced on every page

One change per run. Read it, trace it, then run it. Flat gates only (loops may nest, gates may not). Every while names its exit. Graphics windows always use the while running loop with the QUIT listener; no pygame.event.pump(), no windows that close themselves. Words in the terminal, play in the window. Excluded from the whole week: return values, dictionaries, classes, break, try/except, file I/O, sprites and image files. Every day ends with floor / middle / stretch exit gates, and the floor is a complete, runnable program.
