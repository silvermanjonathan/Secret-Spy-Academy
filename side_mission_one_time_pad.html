The One-Time Pad

Every cipher in this Academy can be cracked by someone patient enough. Except one. Give every letter its own random key, use the pad once, and burn it: mathematicians proved no codebreaker, no computer, no century of trying can open it. The catch is the burning, and this mission shows you exactly why.

Drill 1 · Rolling the padE5-PRO-VD-?? ⚠

A keyword as long as the message, chosen by dice

The Unbreakable Wheel's weakness was its rhythm: the keyword repeats. Kill the rhythm by making the keyword as long as the message and picking every letter with the Dispatcher. That string of luck is the pad. The seed here is only so your run matches the box; a real pad is rolled once and never printed twice.

import random

rack = "ABCDEFGHIJKLMNOPQRSTUVWXYZ "
random.seed(9)
message = "GO AT ONCE"
pad = ""
for letter in message:
    pad = pad + random.choice(rack)
print("Pad:", pad)
Predict How many letters will the pad have, and why does the loop read the message if it never uses letter? Could two recruits with different seeds ever roll the same pad?
Ten letters, one per message character including the spaces: the loop uses the message as a measuring stick, running once per character while ignoring what the character is. And yes, two recruits could roll the same pad the way two decks could shuffle identically: possible, and so unlikely that spies bet their lives on it. Twenty-seven choices ten times over is 27 multiplied by itself ten times, a number with fifteen digits.

Drill 2 · Locking with the padE5-PRO-VD-?? ⚠

Every position, its own private key

Encoding is the Wheel's move with the pad standing in for the marching keyword: message slot plus pad slot, wrapped. No % on the position this time, because the pad never cycles; position i simply uses pad letter i.

import random

rack = "ABCDEFGHIJKLMNOPQRSTUVWXYZ "
random.seed(9)
message = "GO AT ONCE"
pad = ""
for letter in message:
    pad = pad + random.choice(rack)
coded = ""
i = 0
for letter in message:
    slot = 0
    for j in range(27):
        if rack[j] == letter:
            slot = j
    pslot = 0
    for j in range(27):
        if rack[j] == pad[i]:
            pslot = j
    coded = coded + rack[(slot + pslot) % 27]
    i = i + 1
print("Coded:", coded)
Predict G is slot 6 and the pad opens with O, slot 14. What is the first coded letter? And the deep question: the coded text has two Us. Can a codebreaker conclude the message had two of anything?
Slot 20, U. And no: the two Us came from different message letters wearing different pad letters, and every such coincidence is pure luck. That is the proof's whole shape: with a truly random pad, any coded text could have come from any message of that length, each exactly as likely, so the intercept tells the enemy nothing but the length. Cryptographers call it perfect secrecy, and this small program has it.

Drill 3 · Unlocking with the same padE5-PRO-VD-?? ⚠

The complement, one position at a time

The receiver holds an identical pad booklet. Decode is the Wheel's complement move: coded slot plus 27 minus the pad slot, wrapped.

import random

rack = "ABCDEFGHIJKLMNOPQRSTUVWXYZ "
random.seed(9)
message = "GO AT ONCE"
pad = ""
for letter in message:
    pad = pad + random.choice(rack)
coded = "UGKIXEINMU"
opened = ""
i = 0
for letter in coded:
    slot = 0
    for j in range(27):
        if rack[j] == letter:
            slot = j
    pslot = 0
    for j in range(27):
        if rack[j] == pad[i]:
            pslot = j
    opened = opened + rack[(slot + 27 - pslot) % 27]
    i = i + 1
print("Opened:", opened)
Predict What prints? And the operational question: this program rebuilds the pad with random.seed(9). In the field, what physical object replaces that line?
Opened: GO AT ONCE. In the field, the seed line is a booklet: two identical copies of printed random letters, one in each agent's pocket, made in advance and never transmitted. Real pads crossed borders as microfilm and cigarette-paper booklets, and the Moscow-Washington hotline ran on exactly this machine. The pad never travels with the message; that separation is the entire security.

Drill 4 · The deadly reuseE5-PRO-PD-?? ⚠

Why the pad burns after one use

A lazy agent encodes two different messages with the same pad. Watch what the two coded texts confess when you lay them side by side.

import random

rack = "ABCDEFGHIJKLMNOPQRSTUVWXYZ "
random.seed(4)
first = "MEET AT SIX"
second = "MEET AT TWO"
pad = ""
for letter in first:
    pad = pad + random.choice(rack)
coded_one = ""
i = 0
for letter in first:
    slot = 0
    for j in range(27):
        if rack[j] == letter:
            slot = j
    pslot = 0
    for j in range(27):
        if rack[j] == pad[i]:
            pslot = j
    coded_one = coded_one + rack[(slot + pslot) % 27]
    i = i + 1
coded_two = ""
i = 0
for letter in second:
    slot = 0
    for j in range(27):
        if rack[j] == letter:
            slot = j
    pslot = 0
    for j in range(27):
        if rack[j] == pad[i]:
            pslot = j
    coded_two = coded_two + rack[(slot + pslot) % 27]
    i = i + 1
print(coded_one)
print(coded_two)
Predict The two messages agree on their first eight characters and differ on the last three. Where will the two coded lines match, and what does a watching enemy learn without ever touching the pad?
They match on exactly the first eight positions and split at the last three, because wherever the messages agree, same letter plus same pad letter gives the same coded letter. The enemy, holding only the two intercepts, now knows the two messages open identically and diverge at the tail, and with a guess like MEET AT, the pad itself starts falling out. Reuse turns perfect secrecy into a window. Hence the name, and the burning: one time means one time.

The price of perfection

Part 1: your message is 40 characters. How long must the pad be, and how much of it is left for the next message?
Part 2: an agent's pad is only 5 letters, so their program cycles it with i % 5. What cipher have they actually built, and which mission already broke it?

Part 1: 40 letters, and none is left: the pad spends itself letter for letter, which is why real pads were printed as thick booklets and why perfect secrecy never conquered the world; the key is as heavy as everything you'll ever say. Part 2: they've built the Unbreakable Wheel with a five-letter keyword, rhythm and all, and Babbage's attack from that mission's Drill 3 reveal applies. The pad's magic is not the randomness alone; it is randomness that never repeats.
Field Mission · The Pad Booklet

One page, one message, one match

Part A, print page one: agree a seed number with a partner out loud; that number is your shared booklet. Each of you runs Drill 1's roller with the agreed seed and your message length, and confirms you hold the same pad.

Part B, the drop: you encode with the pad, pass only the coded text, and your partner opens it with Drill 3's machine. Then both of you cross the seed off: that page is burned.

Part C, stretch: break the rule once, on purpose, with two messages of your own that share an opening, and show a third classmate what the side-by-side confesses.

The seed stands in for the booklet, and saying it aloud is this exercise's one honest cheat: a real seed spoken across a room is a key handed to every listener, the very problem the Shared Secret mission exists to solve. Chain the two missions and you have the real architecture: agree a secret in the open, then spend it as a pad. That chain, industrialized, is roughly how the internet's traffic is guarded tonight.

Standards, pacing & evidence (teacher panel)

Where this fits: forty-five minutes, terminal only, sequenced after the Unbreakable Wheel, whose keyword march it deliberately completes: pad equals keyword stretched to message length and never reused. The perfect-secrecy claim is real (Shannon proved it) and stated at a Grade 5 altitude: any message of that length could have produced the intercept. Drill 4 is the mission's heart; the reuse leak is visible to the naked eye and needs no algebra.

Where recruits actually stall: the measuring-stick loop in Drill 1 (using the message's length while ignoring its letters) reads as wasteful to sharp recruits; the reveal names it and it becomes a favorite. In Drill 4, recruits expect the whole lines to differ and the eight matching characters land as a genuine shock; let the room stare before anyone speaks. The build's seed-spoken-aloud cheat should be called a cheat out loud, because the Shared Secret mission is its payoff.
