What a trace does: it runs a program with a pencil instead of a terminal.
  1. One row for every line of code, in the order Python runs them.
  2. One amber column for every briefcase (variable) in the program.
  3. After each line, write what each briefcase holds right now. Put a dash in a box that holds nothing yet.
  4. When a line refills a briefcase, cross out the old value and write the new one beside it. Never erase. The crossing-out is the point.
Worked example · done for you

The twice-filled briefcase (Day 1)

#Codeclearance briefcaseOutput
1clearance = 22–
2print(clearance)22
3clearance = 52  5–
4print(clearance)55
Look hard at line 3. The 2 gets crossed out. A briefcase holds one value, and = swaps: the old value is gone. After line 3, clearance is 5, and 5 is the only thing inside.
Trace 1 · Day 1, the Induction Terminal

Nightjar reports 4 missions

The recruit's codename is Nightjar and they have completed 4 missions. Trace all four lines.

#CodecodenamemissionspointsOutput
1codename = input("...Recruit: ")
2missions = int(input("...completed? "))
3points = missions * 15
4print(f"{codename}, your file shows ...")
Line 1: codename = Nightjar · missions – · points – · output: the question, then the terminal waits.
Line 2: codename = Nightjar · missions = 4 · points – · output: the question, then the terminal waits.
Line 3: codename = Nightjar · missions = 4 · points = 60 · no output; this line only does math.
Line 4: nothing changes · output: Nightjar, your file shows 60 field points.
Two self-checks: missions holds the number 4, because int() decoded it on arrival; text "4" times 15 would have made a string of fifteen 4s at line 3. And points is empty until line 3 runs; a briefcase isn't born before the line that makes it.

Where does each row start? How far does each rule move per pass? The relationship between the two patterns, in my own words:

Rule 1: 70, 170, 270, 370, 470, 570. Rule 2: 70, 120, 170, 220, 270, 320. Both rows start at 70. Rule 1 moves 100 per pass and rule 2 moves 50, so every beacon in rule 1 sits twice as far from the start as its partner in rule 2: the gaps in the first row are exactly double the gaps in the second.
